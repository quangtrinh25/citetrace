# Changelog

## 0.1.0-alpha.1 — 2026-09-07

- Local paper/anchor/link/decision ledger, strict schema, atomic writes and revisions.
- Manual/DOI/arXiv metadata, paper CRUD/refresh/merge and offline cache.
- Python/notebook CLI audit, decisions, repair and protected BibTeX export.
- Ten limited AST detectors and explicit human confirmation.
- VS Code sidebar, commands, hover, diagnostics and native notebook support.
- Background workers, debounce, cancellation, bundled CLI/VSIX and install smoke.

Initial GitHub alpha; not a stable release. Independent detector evaluation and a real-user
pilot remain outstanding. See docs/progress.md for actual verification.
